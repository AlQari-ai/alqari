# ALQari API Documentation

Welcome to the ALQari Developer Hub. ALQari is an Arabic-first Document Intelligence API that converts Arabic and English documents into structured, machine-readable data — OCR, structured OCR (text, confidence, bounding boxes), layout analysis, rule-based validation, document Q&A, and workflow automation.

> The authoritative, always-current API reference lives at **[alqari.sa/api-docs](https://alqari.sa/api-docs)**.
